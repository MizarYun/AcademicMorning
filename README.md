# 学术晨报 (Academic Morning)

**学术晨报APP** 是一款面向科研工作者的智能文献推送与阅读管理工具。

## 功能特性

- **每日晨报推送**：基于用户偏好的学科领域，每日自动推送最新学术论文
- **多源文献检索**：集成 arXiv、Crossref、PubMed 等学术数据源
- **AI 摘要翻译**：支持论文标题和摘要的智能翻译
- **期刊收藏管理**：自定义关注期刊，精准获取目标领域文献
- **阅读统计**：追踪阅读时长和习惯，量化科研投入
- **离线阅读**：支持论文收藏与离线阅读

## 技术栈

- Kotlin / Jetpack Compose
- Room 数据库
- WorkManager 后台任务
- Retrofit 网络请求
- Material Design 3
